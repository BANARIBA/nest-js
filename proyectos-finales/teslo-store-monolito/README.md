# Proyecto tienda

## Pasos para levantar el proyecto
1. Clonar o descargar el proyecto
2. Copiar el archivo __.env.template__ y pegarlo como __.env__, luego de eso, establecer las variables  de entorno
3. Instalar dependencias con el comando ```npm i```
4. Ejecutar proyecto ```npm run start:dev```

## Instalaciones del proyecto
- (Manejo de variables de entorno)[https://docs.nestjs.com/techniques/configuration]
- ```npm i --save @nestjs/config```
- (Validacion de entrada de datos con DTOs)[https://docs.nestjs.com/techniques/validation]
```npm i --save class-validator class-transformer```
- (TypeOrm usando PostgreSql)[https://docs.nestjs.com/recipes/sql-typeorm]
```npm install --save @nestjs/typeorm typeorm pg```
